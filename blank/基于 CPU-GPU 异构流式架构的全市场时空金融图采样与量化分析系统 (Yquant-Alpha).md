## 1. 现实语境

本系统旨在解决量化金融初学者在高频极端行情下的"信息孤岛"困境。

**用户困境（孤立时序的盲区）**：传统个人量化分析依赖单只资产的纵向时间序列（如均线、MACD），面对盘中流动性危机或高频板块轮动时全线钝化。初学者极易误买边缘跟风股，或在组合构建时持有资金高度重合、存在强隐性联动的资产，承受超预期的系统性风险。

**应用定位（动态全市场雷达）**：用户调用本模块后，系统实时重构盘口资金的真实流动网络，通过量化计算个股网络向心度（Graph Centrality），在极端行情中剥离虚假信号，锚定资金风暴中心。

**优雅降级**：无 GPU 环境下系统自动降级为单机 CPU 异步模式，保证基础可用性；进阶用户开启 `use_gpu=True` 即可启用异构算力加速。

## 2. 并行算法设计

本项目底层重构为异构计算管线，对应课程中前沿论文复现、多 GPU 编程及外存计算的相关要求。

**前沿论文结合点**：复现前沿论文中时空图神经网络（Spatio-Temporal GNNs）与时变图遍历（Traversal Based Sampling）的底层算子，通过高频分钟级数据构建三维时空张量，并实施跨时空马尔可夫随机游走采样（Temporal Random Walk Sampling）。

**三层异构架构**：

1. **CUDA Tensor Core 张量并行**：时空动态邻接矩阵的生成完全在 GPU 侧完成，利用 Tensor Core 加速大规模协方差矩阵乘法。
2. **Warp 级合并访存优化**：通过 CSR 内存对齐与 cuRAND 随机数生成，解决随机游走的访存分歧，最大化显存带宽吞吐。
3. **MPI 跨节点调度**：将不同市场或时间跨度的数据流分发至多个异构节点，实现强规模伸缩性。

## 3. 基准测试

**数据集**：Kaggle "Optiver Realized Volatility Prediction" 高频订单簿数据集，解压后约 3–5 GB。该体积超越多数单机内存安全阈值（直接 `pandas.read_csv` 将导致 OOM），切分为单次 10 分钟切片（约 100 MB）后又远低于显存上限，是验证外存计算的理想规模。

**压测方案**：采用内存映射（Memory-Mapping）流式切片读取，通过双 CUDA Stream 实现异步重叠——`Stream A` 向 GPU 传输 $T_1$ 切片的同时，`Stream B` 对 $T_0$ 切片执行随机游走采样，使 PCIe 传输与 GPU 计算完全并行。

## 4. 预期结果

最终报告将输出三种模式的绝对耗时对照与加速比（Speedup）/并行效率（Efficiency）曲线：

| 模式                                     | 预期加速比 |
| ---------------------------------------- | ---------- |
| 纯 CPU 串行（基准）                      | 1×         |
| 单机多核 CPU（OpenMP）                   | 4–8×       |
| CPU-GPU 异构流水线（Out-of-Core + CUDA） | 30–80×     |

预期 GPU 异构模式在 5 GB 全量数据上的端到端处理时延控制在分钟级以内，Out-of-Core 流水线的显存峰值占用稳定低于单张 GPU 显存容量的 60%，验证系统在受限硬件条件下的工程可行性。
